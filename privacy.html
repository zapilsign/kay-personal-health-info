개인정보처리방침

시행일: 2026년 11월 10일

이 방침은 운영자 본인이 사용하는 개인용 앱 Kay Personal Health와 그 공개 안내 사이트에 적용됩니다. 문의 및 삭제 요청 연락처는 zapilsign@gmail.com입니다.

1. 처리하는 데이터와 목적

본인이 Google 계정 접근을 승인한 경우, Google Health API가 제공하고 승인 범위에 포함되는 수면, 활동, 신체 지표, 영양 및 수분 섭취 데이터를 읽기 전용으로 조회합니다. 개인 기록 정리, 데이터 출처 확인, 변경 이력 보존 및 추이 확인에만 사용하며, Google의 원본 건강 기록을 수정하지 않습니다. 연결에 필요한 인증·권한 정보는 비공개로 관리하며 이 공개 사이트나 저장소에 포함하지 않습니다.

2. 저장 및 보관

조회한 원본 데이터, 출처 정보, 정리된 기록 및 변경 이력은 운영자가 관리하는 비공개 로컬 저장소에 보관합니다. 개인 기록 관리 목적에 필요한 동안 보관하고, 운영자가 사용을 종료하거나 삭제를 요청하면 보관 사본과 이력을 확인하여 삭제합니다. 백업 사본이 있다면 삭제 범위와 잔존 여부도 함께 확인합니다. 이 방침은 저장 장치의 암호화 여부를 보장하지 않습니다.

3. 이용·제공의 제한

건강 데이터를 판매하거나 광고, 광고 타기팅 또는 공개 전시에 사용하지 않습니다. Google API에서 받은 정보의 다른 앱으로의 사용 및 전송은 Limited Use 요건을 포함한 Google API Services User Data Policy를 준수합니다. 허용된 개인 기록 관리 목적을 벗어난 전송이나 범용 AI·머신러닝 모델 학습에는 사용하지 않습니다.

4. 외부 서비스와 공개 사이트

인증과 데이터 조회에는 Google 서비스가 관여합니다. 실제 처리에 사용하는 도구나 외부 서비스가 있는 경우 해당 처리 경로와 정책도 적용되며, 모든 처리가 로컬에서만 이루어진다고 보장하지 않습니다. 이 안내 사이트는 GitHub Pages에서 제공하므로 접속 시 IP 주소 등 기술적 접속 정보가 호스팅 제공자에 의해 처리될 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요. 이 사이트 자체에는 분석 스크립트, 광고, 입력 폼, 건강 데이터 수집 기능이 없습니다.

5. 연결 해제와 데이터 삭제

Google 계정의 보안 설정에서 앱 접근 권한을 철회하여 향후 조회를 중단할 수 있습니다. 권한 철회만으로 이미 로컬에 보관된 원본, 정리된 기록 및 변경 이력이 자동 삭제되지는 않습니다. 보관 데이터의 삭제는 운영자가 로컬 저장소와 관련 사본을 별도로 삭제해야 합니다. 연결 해제 또는 삭제에 관한 문의는 위 이메일로 연락할 수 있으며, 문의 시 건강 기록이나 인증 정보를 첨부하지 마세요.

6. 방침 변경

처리 목적이나 데이터 흐름이 변경되면 이 페이지와 시행일을 갱신합니다. 이 공개 사이트에는 로그인·연결·실행 기능이 없으며 개인 건강 기록을 게시하지 않습니다.
